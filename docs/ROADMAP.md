# Ruinborne Roadmap

## Alpha 0.2.x — Progression Foundation

Primary goals:

- [x] Complete the six-tree RPG talent foundation, branch capstones, and signature skill identities
- Define early, mid, late, and endgame progression stages
- Gate advanced technology and Aeronautics intentionally
- Balance Waystones and other travel systems so exploration still matters
- Tune Create Ore Excavation and other automation systems
- Verify exact recipe and item IDs before KubeJS recipe changes
- Begin loot and structure-frequency tuning

Alpha 0.2.10 closes the first skill-system chapter with 147 tested talents across Combat, Survival, Exploration, Arcane, Engineering, and Aviation. Future skill work in the 0.2.x line should focus on XP pacing and balance rather than expanding the trees.

## Alpha 0.3.x — Adventure Progression

Planned focus:

- Boss progression order
- Dungeon reward tiers
- Artifact and relic balance
- Dimension progression
- Structure rarity and spacing
- Exploration-based progression materials where appropriate

## Alpha 0.4.x — Technology Integration

Planned focus:

- Cross-mod recipe integration
- Create → Immersive Engineering → Powah → Mekanism progression
- Aeronautics unlock path
- Advanced machinery gating
- Airship component balance
- Create Big Cannons and war-machine progression

## Alpha 0.5.x — Multiplayer and World Balance

Planned focus:

- Multiplayer loot and progression checks
- Waystone and travel economy
- FTB Chunks / teams behavior
- Server performance
- Structure density and world-generation stress testing

## Pre-Beta

Before beta, Ruinborne should have:

- Stable progression from early game through endgame
- Intentional dungeon and boss reward structure
- Stable singleplayer and multiplayer world creation
- No known dependency-chain failures
- Finished core branding and menu configuration
- Performance baseline on typical client hardware
- Upgrade notes for world-breaking changes

## Scope Rule

New mods are not added simply because they are compatible or interesting.

A new mod must either:

1. Strengthen one of Ruinborne's core pillars: exploration, treasure, bosses, engineering, or airships; or
2. Solve a specific gameplay, compatibility, or performance problem.

If it does neither, it stays out of the pack.
